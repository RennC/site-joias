# Critérios de aceitação

O projeto poderá ser considerado pronto quando todos os itens aplicáveis estiverem marcados.

## Base técnica

- [ ] O projeto usa Astro e TypeScript.
- [ ] React é usado somente em componentes com interatividade complexa.
- [ ] A compilação gera um site totalmente compatível com GitHub Pages.
- [ ] Links, rotas e mídias funcionam no subdiretório do GitHub Pages.
- [ ] O site está publicado e foi testado no endereço final.
- [ ] Não há segredos nem arquivos gerados indevidamente no Git.

## Página principal

- [ ] O cabeçalho mostra logo e nome à esquerda.
- [ ] A navegação mostra Sobre Mim, Catálogo, Feedbacks, Principais Dúvidas, Eternize seu Amor e Parceiros, nessa ordem.
- [ ] Cada link leva à área correta.
- [ ] Sobre Mim mostra foto e texto da proprietária lado a lado quando houver espaço.
- [ ] A animação de Sobre Mim ocorre novamente ao sair e voltar à área visível.
- [ ] O catálogo é gerado de uma fonte de dados única e mantém layout consistente.
- [ ] Cada produto mostra foto, preço e descrição.
- [ ] A página inicial mostra a quantidade de joias produzidas configurada manualmente.
- [ ] Parceiros mostram nome e link correto para o Instagram.
- [ ] O rodapé contém um botão para o Instagram oficial.

## Feedbacks

- [ ] O carrossel aceita fotos e vídeos.
- [ ] Fotos avançam após cinco segundos.
- [ ] Vídeos avançam ao terminar.
- [ ] A troca de arquivos e caminhos está documentada.
- [ ] Todas as mídias e identificações têm autorização de publicação.

## Principais Dúvidas

- [ ] Perguntas e respostas vêm de uma fonte de dados editável.
- [ ] O conteúdo aparece como diálogo entre dois animais cartoon aprovados.
- [ ] Os balões evitam blocos longos de texto.
- [ ] A leitura e a navegação permanecem acessíveis sem depender apenas das ilustrações.

## Eternize seu Amor

- [ ] Todas as perguntas e opções de `CONFIGURATOR_SPEC.md` estão presentes.
- [ ] Apenas opções compatíveis aparecem em cada caminho.
- [ ] Outro exige a identificação do animal.
- [ ] Alterar uma resposta anterior limpa escolhas que se tornaram inválidas.
- [ ] O preço é atualizado após cada escolha relevante.
- [ ] Todos os caminhos válidos chegam à tela final.
- [ ] A tela final mostra preço, imagem genérica, aviso sobre a imagem, tutorial e alerta do frete.
- [ ] Finalizar não registra cliques nem depende de armazenamento externo.

## WhatsApp

- [ ] O número de destino está correto.
- [ ] A mensagem não contém emojis.
- [ ] A mensagem contém todas as escolhas e o valor final.
- [ ] O fluxo foi testado em celular e computador.
- [ ] A mensagem só é enviada após ação da pessoa no WhatsApp.

## Qualidade, acessibilidade e movimento

- [ ] O site é responsivo.
- [ ] Funciona com teclado nas áreas interativas.
- [ ] Imagens têm textos alternativos apropriados.
- [ ] Vídeos oferecem controles e alternativa acessível.
- [ ] Contraste, foco visível e tamanho dos controles foram verificados.
- [ ] Movimentos respeitam a preferência de redução de animações do dispositivo.
- [ ] Links, botões, preços e caminhos de mídia foram testados.

## SEO

- [ ] Cada página tem título e descrição próprios.
- [ ] URL canônica, sitemap e `robots.txt` usam o endereço final.
- [ ] Metadados de compartilhamento estão preenchidos.
- [ ] Dados estruturados usados correspondem ao conteúdo visível.
- [ ] Não há erros visíveis no carregamento da versão publicada.
